# Manga emoji art

Nine PNG drawings the anime theme shows next to the bubble when a message contains one of their
emoji (`emoji_art` in `../theme.json`, ADR-0027).

- **Origin:** supplied by the owner on 2026-10-24, generated by an AI image service (not yet named).
  The text labels under the drawings were cropped off; no other change.
- **Status:** not publishable. docs/legal.md L30 blocks any public build containing them; local
  debug builds only.
- `tristesse.png` and `calme.png` will be replaced by unlabelled versions from the owner.
